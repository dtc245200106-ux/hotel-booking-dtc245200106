## Mô tả
Website đặt phòng khách sạn được xây dựng với kiến trúc microservices, triển khai bằng Docker Compose.

## Công nghệ sử dụng
- Backend: NodeJS
- Database: PostgreSQL + pgAdmin
- Reverse Proxy: Nginx
- Monitoring: Prometheus + Grafana
- Logging: Loki + Promtail
